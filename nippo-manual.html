ヤハタ電機商会　業務日報

業務日報の入力マニュアル

上から順に入れていくだけ。訪問1件ごとに1回送信します。

📱 開き方：スマホのブラウザで日報のURLを開く → 初回に「ホーム画面に追加」しておくと次回すぐ開けます。
1日付・時間帯・担当者
  • 日付：当日が自動で入ります（違えば直す）
  • 時間帯：午前／午後などを選ぶ（複数可）
  • 担当者：自分を選ぶ 必須
2訪問先（お客様）を入れる
  • 🔍 顧客検索に名前・電話・住所・カタカナを入れると候補が出る → 選ぶと訪問先名に入る
  • 候補になければ「訪問先名」に直接入力（例：山田太郎様） 必須
3作業内容を選ぶ（複数可）

必須　やったことを選びます。選ぶと、その種類に応じた入力欄が下に出ます。

通常： お困りごと対応点検商談集金その他

📄 報告書あり（PDFが自動で作られる）： 現調配達工事修理

選んだ種類追加で入れること
お困りごと対応要件（何の用事で伺ったか） 必須
点検エアコン点検・その他点検の台数
配達商品（大分類→カテゴリを選ぶ） 必須
工事工事種類（複数可） 必須
修理機器種類・症状・修理内容
現調現調内容／見積書があれば「見積書あり」にチェック
商談・集金・その他特になし（メモに記入）
4金額・人数・集金
  • 売上金額：千円単位・半角で（例：50 → 5万円）。無ければ0のまま
  • 作業人数：報告書ありの作業では選ぶ 必須
  • 集金方法：現金／売掛などを選ぶ。売掛のときは集金方法・入金時期も選ぶ
5写真をあげる
  • 写真の種類（現調写真／完了写真）を選んでから撮影・選択
  • 現調写真 → 現調写真フォルダ、完了写真 → 完了写真フォルダに自動保存
  • 1件あたり最大16枚
⚠️ 報告書（PDF）は「報告書ありの作業＋写真あり」で自動作成されます。写真がないと報告書は作られません（画面にも注意が出ます）。
6見込商品・メモ
  • 見込商品：次につながりそうな商品があれば「➕ 見込商品を追加」（任意）
  • メモ：気づいた点を記入。お困りごと対応は「要件」、点検・商談・集金・その他はメモが必須

※ お困りごと対応のときは、シートに「要件 / メモ」の形で1行にまとまって記録されます。

7送信する
  • 「📤 日報を送信する」を押す → 「✅ 送信完了」が出ればOK
  • 訪問が複数あれば、1件ごとに1回ずつ送信

⛔ これが入っていないと送信できません

  • 担当者 ／ 訪問先名 ／ 作業内容
  • 配達 → 商品を選ぶ
  • 工事 → 工事種類を選ぶ
  • お困りごと対応 → 要件を書く
  • 点検・商談・集金・その他 → メモを書く
  • 報告書ありの作業 → 作業人数を選ぶ
  • 売掛のとき → 集金方法・入金時期を選ぶ
📋 送信した日報は、毎日20時（当日分）と翌朝8時（前日分）にまとめてLINEに届きます。
朝8時は「20時より後に書いた日報」も拾い直すためのものです。
